# Автоматическая разметка с помощью LLM

**Статус:** необязательное расширение.

**Родительский документ:** [Идея продукта](../PRODUCT_CONCEPT.md).

**Обязательная зависимость:** базовый продукт и его правила разметки.

Расширение подчиняется [соглашениям родительского документа](../PRODUCT_CONCEPT.md#10-соглашения-с-расширениями).

## Назначение

Большая языковая модель (**LLM**) назначает элементам теги из текущего набора тегов рабочей области. Автоматическая разметка доступна при добавлении и переразметке элементов.

## Взаимодействие с базовым продуктом

Расширение добавляет **фоновый режим разметки**, в котором элементы размечает LLM.

Неразмеченные элементы из общего списка могут размечаться в фоновом режиме. Для фоновой работы действуют [общие правила разметки](../PRODUCT_CONCEPT.md#8-работа-с-элементами).

За соответствие назначаемых тегов содержанию при автоматической разметке отвечает LLM.
