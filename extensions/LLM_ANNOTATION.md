# Автоматическая разметка с помощью LLM

**Статус:** необязательное расширение.

**Родительский документ:** [Идея продукта](../PRODUCT_CONCEPT.md).

**Обязательная зависимость:** базовый продукт и его правила разметки.

**Дополнительное взаимодействие:** [импорт и экспорт](IMPORT_EXPORT.md) позволяет применять автоматическую разметку к импортированным элементам. Для работы с элементами, добавленными пользователем, это расширение не требуется.

Расширение подчиняется [соглашениям родительского документа](../PRODUCT_CONCEPT.md#10-соглашения-с-расширениями).

## Назначение

Большая языковая модель (**LLM**) назначает элементам теги из глоссария рабочей области. Автоматическая разметка доступна при добавлении и переразметке элементов.

## Взаимодействие с базовым продуктом

Расширение добавляет **фоновый режим разметки**, в котором элементы размечает LLM. Ручная разметка остаётся доступной.

Новые элементы, сохранённые без разметки, могут размечаться в фоновом режиме из общего списка неразмеченных. Для фоновой работы действуют общие правила возобновляемой разметки, атомарности разметки каждого отдельного элемента и визуального обозначения прогресса. Размеченные элементы участвуют в выборках независимо от готовности остальных по правилам базового продукта.

За соответствие назначаемых тегов содержанию при автоматической разметке отвечает LLM. Изменение теговой разметки обновляет время последнего изменения элемента по общему правилу. При переразметке действуют общие настройки доступности исходной разметки; после завершения переразметки элемента она не сохраняется.

## Совместная работа с импортом

При наличии расширения импорта и экспорта LLM может размечать импортированные элементы, которым требуется разметка по глоссарию принимающей рабочей области.

Необходимость переразметки определяется правилами импорта. Автоматическая разметка не меняет решения о сохранении разметки уже имеющихся элементов и не изменяет правил разрешения различий названий.
