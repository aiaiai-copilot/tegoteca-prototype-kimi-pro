# Импорт и экспорт

**Статус:** необязательное расширение.

**Родительский документ:** [Идея продукта](../PRODUCT_CONCEPT.md).

**Обязательная зависимость:** базовый продукт, включая ручную разметку и список неразмеченных элементов.

Расширение подчиняется [соглашениям родительского документа](../PRODUCT_CONCEPT.md#10-соглашения-с-расширениями).

## Назначение и варианты переноса

**Экспорт** — передача данных из рабочей области.

**Импорт** — приём данных в рабочую область.

**Исходная рабочая область** — рабочая область, из которой передаются данные.

**Принимающая рабочая область** — рабочая область, в которую поступают данные.

Продукт должен распознавать повторный импорт того же элемента.

Расширение поддерживает перенос элементов всей рабочей области или её части.

При экспорте из текущего узла пользователь выбирает состав экспортируемых элементов:

- Только собственные элементы текущего узла.
- Выборку текущего узла.

При экспорте теговая разметка элементов сохраняется в экспортируемых данных.

## Названия при повторном импорте

Если название импортируемого элемента отличается от названия того же элемента в принимающей рабочей области, продукт спрашивает пользователя, как поступить с названием. Это правило действует независимо от происхождения названий и состояния разметки элемента.

Пользователь может решить отдельно для каждого элемента, какое название сохранить, либо применить одно решение ко всем различиям названий в текущем импорте: сохранить названия принимающей рабочей области или принять импортируемые.

## Разметка при импорте

Правила разметки применяются как при импорте всей рабочей области, так и при импорте её части.

При повторном импорте уже размеченного элемента сохраняется разметка принимающей рабочей области.

Повторный импорт уже имеющегося неразмеченного элемента не создаёт копию и не изменяет состояние его разметки.

Правила переноса в родительском документе определяют, когда сохранять исходную разметку новых для принимающей области элементов, а когда назначать им теги заново.

## Взаимодействие с разметкой

Элементы, которым требуется разметка в принимающей рабочей области, поступают в общий список неразмеченных для работы по [правилам базового продукта](../PRODUCT_CONCEPT.md#8-работа-с-элементами).

## Открытые вопросы

- Как переносить теги текущего набора рабочей области, которые не назначены ни одному экспортируемому элементу?
- Как переносить поясняющие описания тегов базового глоссария?
