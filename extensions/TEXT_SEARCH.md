# Поиск по тексту внутри текущей выборки

**Статус:** необязательное расширение.

**Родительский документ:** [Идея продукта](../PRODUCT_CONCEPT.md).

**Обязательная зависимость:** базовый продукт и текущая теговая выборка.

**Дополнительное взаимодействие:** взаимодействие с другими расширениями не определено.

Расширение подчиняется [соглашениям родительского документа](../PRODUCT_CONCEPT.md#10-соглашения-с-расширениями).

## Назначение и границы

Расширение позволяет искать элементы по словам их текстового содержания внутри текущей теговой выборки, в том числе по словам, которые не являются тегами.

## Взаимодействие с базовым продуктом

Область поиска определяется выбранными пользователем тегами по общим правилам теговой выборки. Поиск использует содержание элемента; содержание и теговая разметка остаются отдельными свойствами.
