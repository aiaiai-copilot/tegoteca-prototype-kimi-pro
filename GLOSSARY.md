# Иерархия теговых узлов

Термины продукта для организации и поиска элементов разных типов через теги. Ментальная модель использует аналогию с папками и файлами; структура узлов и их соседство описываются направленными ациклическими графами (DAG).

## Элементы и теги

**Рабочая область**:
Совокупность записей разных типов, организованных с помощью тегов из глоссария.

**Глоссарий тегов**:
Глоссарий, задающий используемые в рабочей области теги. Он создаётся или выбирается пользователем либо предполагается по умолчанию.

**Версия глоссария**:
Определённое состояние глоссария. Продукт различает версии и распознаёт одну и ту же версию при переносе между рабочими областями.

**Полный глоссарий**:
Глоссарий со всеми тегами рабочей области, независимо от их использования в экспортируемых элементах.

**Сокращённый глоссарий**:
Глоссарий, содержащий только использованные в экспортируемых элементах теги исходного глоссария рабочей области. Рассматривается как самостоятельный глоссарий, отличный от полного исходного.

**Элемент**:
Запись, которой могут быть назначены теги. Содержание записи отделено от её теговой разметки и может быть пустым. При переносе и изменении разметки запись считается тем же элементом; при изменении содержания результат считается другим элементом и заменяет исходную запись в рабочей области.

**Размеченный элемент**:
Элемент с завершённой разметкой по глоссарию данной рабочей области. Завершённая разметка может содержать пустой набор тегов. Участвует в выборках независимо от готовности остальных элементов.

**Неразмеченный элемент**:
Элемент, разметка которого по глоссарию данной рабочей области ещё не завершена. Не участвует в её выборках.

**Содержание элемента**:
Текст, изображение, аудиозапись, видеозапись или другое содержимое элемента, отдельное от его тегов. Теги не становятся содержанием элемента; содержание может быть пустым.

**Текстовый элемент**:
Элемент с обозримым текстом: обычно не более одного абзаца, максимум несколько абзацев.

**Тег**:
Обозначение из глоссария, назначаемое элементам и используемое для их отбора в выборку. Теги назначаются пользователем вручную; расширение автоматической разметки позволяет назначать их с помощью LLM.

**Теговая разметка элемента**:
Полный набор тегов, назначенных элементу в данной рабочей области.

**Атомарная разметка элемента**:
Разметка одного элемента, выполняемая как единое неделимое действие.

**Переразметка элемента**:
Повторное назначение тегов элементу по выбранному глоссарию. При импорте используется глоссарий принимающей рабочей области.

**Перемещение элемента**:
Изменение разметки элемента в пределах рабочей области на полный набор тегов узла назначения. Новые теги должны соответствовать содержанию; при необходимости содержание корректируется. Если обеспечить соответствие невозможно, перемещение не выполняется.

**Возобновляемая разметка**:
Разметка, которую можно приостановить и продолжить позже с сохранением выполненной работы.

**Режим разметки**:
Отдельный режим работы с неразмеченными элементами. В базовой функциональности разметку выполняет пользователь вручную; расширение автоматической разметки позволяет выполнять её с помощью LLM в фоновом режиме.

## Узлы и выборки

**Узел**:
Вершина DAG модели, определяемая набором тегов. Разные наборы тегов задают разные узлы, даже если их выборки содержат одинаковые элементы.

**Корень (корневой узел)**:
Узел DAG всех наборов тегов с пустым набором тегов. Его выборка включает все размеченные элементы рабочей области. Собственные элементы корня имеют завершённую разметку с пустым набором тегов.

**Теговая выборка (выборка узла)**:
Определяемая набором тегов совокупность всех размеченных элементов рабочей области, разметка которых содержит все эти теги. Она включает собственные элементы соответствующего узла и собственные элементы всех его потомков.

**Собственный элемент узла (элемент, принадлежащий узлу)**:
Размеченный элемент, теговая разметка которого полностью совпадает с набором тегов узла. В каждой рабочей области размеченный элемент принадлежит ровно одному узлу, но может входить в выборки нескольких узлов.

**Заполненный узел**:
Узел, имеющий хотя бы один собственный элемент. Элемент с пустым содержанием также заполняет узел.

**Незаполненный узел**:
Узел, не имеющий собственных элементов. Его теговая выборка может быть непустой за счёт элементов потомков.

**Непустая выборка**:
Выборка, содержащая хотя бы один элемент. Она может быть непустой за счёт элементов потомков, даже если у соответствующего узла нет собственных элементов.

**Выбранные теги**:
Теги, которые пользователь выбрал как условия отбора элементов. Их совокупность задаёт текущий узел и текущую выборку.

**Текущий узел**:
Узел, набор тегов которого совпадает с тегами, выбранными пользователем для отбора элементов. Он может быть заполненным или не иметь собственных элементов.

**Текущая выборка**:
Выборка текущего узла. Добавление тегов сужает выборку, удаление тегов расширяет её.

## Граф и навигация

**Переход к узлу**:
Действие, в результате которого выбранный узел становится текущим. Выбранные теги, выборка и предлагаемые направления навигации обновляются в соответствии с этим узлом.

**История переходов**:
Упорядоченная последовательность посещений узлов, по которой пользователь может двигаться назад и вперёд. Один и тот же узел может встречаться в истории неоднократно.

**DAG всех наборов тегов**:
Направленный ациклический граф, в котором каждому набору тегов из глоссария соответствует узел, а ребро соответствует добавлению одного тега. Направление рёбер задаёт сужение выборки.

**Потомок узла**:
Узел, достижимый по направлению рёбер и имеющий все теги исходного узла и хотя бы один дополнительный тег. Его выборка включена в выборку исходного узла и может совпадать с ней по составу элементов.

**Предок узла**:
Узел, из которого исходный узел достижим по направлению рёбер. Набор тегов предка строго включён в набор тегов исходного узла.

**Соседние узлы**:
Два узла, один из которых получается из другого добавлением или удалением одного тега. Их заполненность не обязательна.

**Ближайшие заполненные узлы**:
Другие заполненные узлы, для достижения которых требуется наименьшее число изменений тегов среди всех допустимых переходов. Допустимый переход состоит только из добавлений либо только из удалений тегов.

**Соседние заполненные узлы**:
Заполненные предки и потомки текущего узла, между которыми и текущим нет других заполненных узлов. Набор тегов промежуточного узла строго включает меньший из двух наборов и строго включён в больший. Сам текущий узел может не иметь собственных элементов.

**Граф соседства заполненных узлов**:
DAG заполненных узлов, в котором ребро связывает соседние заполненные узлы и направлено от меньшего набора тегов к большему. Одно ребро может соответствовать добавлению нескольких тегов; пользователь может двигаться по рёбрам в обе стороны.
