# Координация импорта, экспорта и самостоятельных глоссариев

**Родительский документ:** [Идея продукта](../PRODUCT_CONCEPT.md).

**Для работы описанного взаимодействия требуются:** [базовый продукт](../PRODUCT_CONCEPT.md), расширения [«Импорт и экспорт»](../extensions/IMPORT_EXPORT.md) и [«Самостоятельные глоссарии тегов»](../extensions/TAG_GLOSSARY.md).

Координацию выполняет родительский модуль в соответствии с [общими соглашениями](../PRODUCT_CONCEPT.md#10-соглашения-с-расширениями).

## Правила взаимодействия

При совместном использовании расширений импорта и экспорта и самостоятельных глоссариев родительский модуль поддерживает перенос всей рабочей области или её части с самостоятельным глоссарием либо без него. При экспорте части рабочей области пользователь может включить самостоятельный глоссарий полностью — со всеми его тегами — или в сокращённом составе, содержащем только его теги, использованные в экспортируемых элементах. Правила различения таких глоссариев определены в расширении [«Самостоятельные глоссарии тегов»](../extensions/TAG_GLOSSARY.md#различение-глоссариев).

Если принимающая рабочая область использует самостоятельный глоссарий через расширение, к новым для неё элементам применяются следующие правила:

| Самостоятельный глоссарий в передаваемых данных | Разметка новых элементов |
| --- | --- |
| Тот же, что используется принимающей областью | По желанию пользователя: сохранить исходную разметку или назначить теги заново. |
| Другой | Все новые элементы размечаются заново. |
| Отсутствует | Все новые элементы размечаются заново. |

При сохранении исходной разметки сохраняется и её состояние: неразмеченный элемент остаётся неразмеченным, а размеченный элемент с пустым набором тегов — собственным элементом корня. При назначении тегов заново должны использоваться теги самостоятельного глоссария, выбранного в принимающей области. Согласование этого требования с текущим набором, содержащим теги вне выбранного самостоятельного глоссария, требует отдельного определения.

Сравниваются самостоятельные глоссарии, используемые в данный момент; история их изменения не учитывается. При переносе с сокращённым самостоятельным глоссарием в область с полным исходным самостоятельным глоссарием все новые элементы должны размечаться заново.

Эти правила действуют для переноса как всей рабочей области, так и её части. Для уже имеющихся элементов сохраняются правила повторного импорта. Отсутствие самостоятельного глоссария в передаваемых данных отличается от случая, когда принимающая область использует только базовый глоссарий: правила разметки новых элементов во втором случае требуют отдельного определения.
