# Цели совместной работы

## Концептуальная разработка продукта

Разработать и согласовать концепцию «Теготеки» без детализации её реализации.

Основное описание — [«Теготека: идея продукта»](PRODUCT_CONCEPT.md).

## Начало разработки методологии

В качестве побочного результата концептуальной разработки продукта заложить основу методологии таких разработок. Общие принципы и правила должны быть пригодны для применения к другим продуктам.

Дальнейшее развитие методологии предполагается как самостоятельная работа, независимая от разработки конкретного продукта.
