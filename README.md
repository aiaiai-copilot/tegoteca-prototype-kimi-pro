# Прототип Теготеки

Локальное браузерное приложение для проверки концепции Теготеки: элементы, текст и файлы, разметка, глоссарий и настройки сохраняются между запусками. Backend и внешние API отсутствуют.

## Запуск

Требуется Node.js 22.12 или новее. Реализация проверена на Node.js 25.9.0 и Google Chrome 157.0.8103.39.

```bash
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173**. Остановите сервер сочетанием **Ctrl+C** в терминале.

Production-сборка и её локальный просмотр:

```bash
npm run build
npm run preview
```

Preview по умолчанию доступен на `http://127.0.0.1:4173`. У разных origin (`localhost`/`127.0.0.1`, разные порты) разные локальные хранилища.

## Работа с данными

Элементы, глоссарий и сами файлы как `Blob` хранятся в **IndexedDB** текущего браузера. Последний узел, режим «Собственные/Выборка», сортировка и настройки хранятся в **localStorage**. Очистка site data удаляет рабочую область; экспорт и синхронизация в прототип не входят.

В правом верхнем углу откройте **«Настройки»**:

- **«Загрузить демонстрационные данные»** заменяет рабочую область на E0–E9 и тег `мечта` из [проверочных сценариев](prototype/CHECKS.md).
- **«Добавить демонстрационные медиа»** отдельно добавляет PNG, WAV, WebM и TXT, не меняя базовый набор.
- **«Создать диагностический набор»** после подтверждения заменяет данные на 10 000 элементов и 100 тегов.
- **«Очистить рабочую область»** после подтверждения удаляет элементы и теги.

Собственные записи создаются кнопкой **«+ Новый элемент»**. Поддерживаются текст, пустое содержание и один файл на элемент, редактирование названия/разметки, замена файла и удаление. Неразмеченные записи обрабатываются кнопкой **«Разметка»**: их можно разметить, изменить или удалить после подтверждения.

Изображения и воспроизведение аудио/видео зависят от форматов, поддерживаемых браузером. Проверены локальные PNG, WAV, WebM и TXT; другие файлы доступны для скачивания. Готовые примеры находятся в `public/media`. Для их повторной генерации требуется установленный Google Chrome:

```bash
npm run media:generate
```

## Проверки

```bash
npm test                 # Vitest: модель, состояние и компоненты
npm run build            # TypeScript и production-сборка
npm run test:e2e         # Playwright, включая диагностический сценарий
npm run diagnostic       # JSON с распределением и модельными замерами
```

Браузерные тесты используют установленный **Google Chrome** (`channel: 'chrome'`), а не скачанный Playwright Chromium. Playwright сам поднимает Vite на `127.0.0.1:5173`, если он ещё не запущен. Каждый тест получает новый browser context; изменяются только его IndexedDB/localStorage. Внешний или production backend отсутствует.

Отдельный диагностический browser-сценарий:

```bash
npm run test:e2e -- --grep '10 000 элементов'
```
